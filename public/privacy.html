Orbital Books privacy policy

Effective 30 October 2026 · Updated 2 November 2026 · Tellim Games

Orbital Books is a game about running a bookstore in orbit and working out what its sales data is telling you. It doesn't collect your name, email, contacts, location or any other personal information, and nothing about you is ever sold. To help us make the game better, it sends us anonymous play data, which you can turn off at any time. This page explains what the game keeps, what it sends us, and what happens to the questions you ask Dewey, the game's reference assistant.

What stays on your computer

  • Your game: the station's date, your decisions and their results.
  • A short log of what happened in the game (for example "investigation opened" or "plan submitted"), kept so problems can be looked into. It has no personal information in it. It's also the play data described below.
  • The questions you type to Dewey, and any sentence of Dewey's reply the game held back instead of showing you. These are kept on your computer and are not sent to us. If that ever changes, this page will be updated first, and the date above will change.

Play data we receive

Unless you turn it off, the game sends us a record of how it's played:

  • What happened in the game, and when: for example "investigation opened", "chart regrouped", "question asked" (with how long it was and how long the answer took, but not the question itself), "plan submitted" and the result. For each page you view, also how often the game reused chart data it had already loaded instead of asking for it again, counted, never what the charts showed.
  • Two random numbers the game makes for itself, so we can tell one player's sessions apart from another's: an install number for your browser, and an instance number for the copy of the game you're running. Neither is a device ID, an account or an advertising ID, and neither can be traced back to you.
  • The game's version, whether it's running as a released build or from source, the version of Node.js that runs it, whether Dewey can reach Claude Code (and why not, if it can't), and your time zone (so we know whether people play in the morning or the evening).
  • What kind of computer it runs on: the browser's graphics chip, how much memory and how many processor cores it has, its screen size, and the version of the browser's engine. Where the browser shares them, also the device's model name and its operating system's version. This tells us where the game runs slowly. It describes the kind of computer, not you. We never record the browser's full user-agent string.

We use it only to understand how the game is played, where players get stuck and why some stop, so we can make it better. It's stored privately with Amazon Web Services in the United States, seen only by Tellim Games, never shared or sold, and never used for advertising. We don't keep your IP address or request logs. Play data is deleted after two years.

Turning it off: in the game's Settings, turn off Share play data. The game then sends no more play data, apart from a note that it was turned off. You can turn it back on the same way.

To have the play data from your install deleted, email us your install number, which is shown under Share play data in Settings.

Dewey, the reference assistant

Dewey answers your questions about the store's data. To do that, your question and the store data needed to answer it are sent to Claude, an AI model made by Anthropic, through Claude Code running on the computer that runs the game, under the Claude account signed in there. Anthropic handles them under that account's terms. Dewey can only read the game's store data: it can't read your files, run programs or browse the web. Don't type anything personal to Dewey.

The quarter's events

From the third quarter on, the game uses Claude the same way to choose each quarter's event from a few the game offers, and to write the memo's story about it. What it sends is game state only: the plans you've submitted, their scores, and the events so far. It never sends anything you've typed. If Claude can't be reached, the game picks the event itself.

What the game doesn't do

  • No accounts or sign-in.
  • No advertising and no advertising identifiers.
  • No third-party analytics, advertising, tracking or crash-reporting services: play data comes only to us.
  • No location, contacts, camera, microphone or photos.

Children

The game doesn't collect personal information from anyone, including children. The play data described above is anonymous.

Deleting your data

Clearing the site's storage in your browser deletes everything the game kept there. The instance number and the server's own log live in the game's .data folder; deleting that folder removes them.

Changes

If a future version changes any of this, this page will be updated before that version is released, and the date above will change.
